## Dwell case (spec 2.2)
`waitToStartMin` was **not** dockedAt→startedAt. The simulator computes it as `startedAt − arrivedAt`
(`src/data/mock/core/api/util.ts`), and docs/01 feature A calls it "wait-to-start" (yard + dock wait). docs/03 had no formula.
So the "otherwise" case applied: added **`preOpMin`** as well as `occupancyMin` and `waitForDockMin`. docs/03 section 4.1 now states the
formula of every dwell field, old and new.

## Decisions (with reasons)
1. **"Visits FINISHED today" = visits completed (departed) in the business day.** This is the sample `avgTatMin` already uses
   (docs/03 calls it "finished visit"; the simulator counts at departure). Depot turnaround, occupancy and post-op all need `departedAt`,
   and `depotTatMin` must equal `avgTatMin`, so any other sample would break that rule. Written into docs/03 section 3.1.
2. **One sample feeds both numbers.** The simulator's `kpi.avgTatMin` is now `turnaround.depotTatMin` (same visits, same whole-minute
   rounding as before), so the equality holds by construction. `BayState.today.avgTatMin` is unchanged.
3. **Per-field means.** Each mean uses the sample visits that have both of its timestamps (a truck that left without loading still counts in
   the depot turnaround and occupancy). Identities hold per visit and for the means when every sample visit is complete (up to rounding).
   Schema refinement: `n = 0` ⇒ every mean `null`. `depotTatMin = avgTatMin` is a contract rule and a simulator test, **not** a schema
   refinement (dropping a whole SiteState over a rounding mismatch would blank the KPI row).
4. **`complianceScore` is PPE-only in the simulator too.** Before: `100 − 1.5·ppe − 10·critical` (critical = on_belt + forklift_proximity),
   which contradicts the new definition. Now `complianceScoreOf(ppe) = 100 − 1.5·ppe` in live, reports and the `/analytics/compliance` score
   series. The mock has no per-observation history, so it remains a penalty proxy for "% of evaluated person-observations"; documented in
   `kpi.ts`. Mock compliance numbers are therefore higher than before (safety events no longer subtract).
5. **`skuCount` excludes `UNKNOWN`** (it is not an identified SKU). Contract rule: `skuCount ≥` the non-UNKNOWN entries of `skuTop`.
   The fixture source sets `skuCount: 0` where it clears `skuTop` (ARRIVED, DOCKED bays).
6. **`Report.kpi.turnaround`.** `Report.kpi` reuses the SiteState kpi schema, so the mock report KPI now carries `turnaround` over the
   visits completed in the report window, and its `avgTatMin` comes from the same aggregate.
7. **`useNow1Hz()` uses stream time**, floored to the second (newest message `ts`, like the existing `useStreamNow`), with the shared 1 Hz
   wall clock before the first message. Reason: in mock speed-up and replay, wall time is wrong for visit timestamps. It re-renders at most
   once per second and has no per-component timer. It stops while the stream is silent (the bay is stale then).
8. **`durHM` rounds to the nearest minute** (averages are fractional: 64.6 → "1h 05m"); `null`/`undefined`/NaN → "—". The existing
   `durMin`/`dur` truncate, which suits elapsed counters.
9. **Relabels.** EN: `kpi.cases` "Cartons today", `kpi.compliance` and `inspector.site.compliance` "PPE compliance", `tray.rate`
   "{{n}} cartons/min", `inspector.site.casesOut/In` "Cartons out/in today", `inspector.bay.casesOut/In` "Cartons out/in". BN:
   "পিপিই কমপ্লায়েন্স"; the inspector out/in labels gain "কার্টন" ("আজ বাইরে যাওয়া কার্টন", ...). `kpi.cases` and `tray.rate` were already
   কার্টন in BN. Not changed: `category.compliance` (the event category, which is about safety, not PPE) and `common` debug readout
   `kinds.case` (the CaseTick channel name in a dev panel). Keys are unchanged, so each word reverts in one place.
   `tray.rate` is outside "chips and inspector" in the brief, but spec section 1 makes cartons the UI word and 19A cannot edit `live.json`.
10. **docs/03 versioning rule.** Its header said "Any change: bump `v`"; the spec says rev 1.1 keeps `v: 1`. The header now distinguishes
    breaking (bump `v`) from additive (revision entry in the Changelog).
11. **Alert groups** resolve an exact key first, then a category wildcard, else `other`. Catalogue types the spec does not name land in
    Other: `truck.arrived/docked/started/finished/departed`, `truck.unknown_plate`, `belt.state_changed`, `handling.rough_handling`.

## API for 19A and 19B (do not edit; report if a change is needed)
`src/features/live/kpiDetail/selectors.ts`
```ts
selectRates(bays: readonly BayState[]): FlowRates            // { outPerHour, inPerHour: number|null; runningBays }
isBeltRunning(bay: BayState): boolean
selectTurnaround(kpi: SiteKpi | null | undefined): TurnaroundView
  // { kind:'none' } | { kind:'legacy'; avgTatMin; avgTatDeltaMin }
  // | { kind:'full'; n; occupancyMin; depotTatMin; depotTatDeltaMin; waitForDockMin; preOpDelayMin; activeMin; postOpDelayMin; shares: PhaseShares|null }
phaseShares(preOp, work, postOp: number|null): PhaseShares | null   // { preOp, work, postOp } summing to 1
selectWorstPpeBay(bays: readonly BayState[]): WorstPpeBay | null    // { bay, count } by today.ppe, ties -> lowest id
ALERT_GROUPS: readonly AlertGroupDef[]; ALERT_GROUP_IDS: readonly AlertGroupId[]
  // AlertGroupId = 'delays'|'idle'|'throughput'|'ppe'|'safety'|'hygiene'|'security'|'system'|'other'
alertGroupOf(category: string, type: string): AlertGroupId
matchesAlertGroup(e: { category; type }, group: AlertGroupId): boolean   // for the Tray filter
selectAlertGroups(events: Iterable<AlertLike>, opts?: { includeEmpty?: boolean }): AlertGroupRow[]
  // AlertGroupRow { id; critical; warn; info; total }, sorted critical, warn, info desc, then table order; CLOSED skipped
selectAttention(kpi): AttentionCounts | null   // { needsAttention = warn + critical; critical; warn; info }
visitTimeline(visit: BayVisit, nowMs: number, direction?: BeltDirection): VisitTimeline
  // { segments: { id: 'preOp'|'work'|'postOp'; min; inProgress }[]; occupancyMin|null; occupancyInProgress; waitForDockMin|null;
  //   work: 'loading'|'unloading'; shares: PhaseShares|null }
workKindOf(visit, direction): WorkKind
```

i18n: `useTranslation('kpidetail')` (19A), `useTranslation('baypanel')` (19B); each file holds one placeholder key `title`.
Group labels are expected at `kpidetail:groups.<AlertGroupId>`.
