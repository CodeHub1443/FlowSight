## Deviations and decisions (read these)
1. **Branding block (22.0b) is missing from this base.** The brief says "created after task-22.0b", but HEAD is task-22.0 (`c7e6d58`) and
   master has no `src/brand.ts`, no `Brand.tsx`, and `public/brand/` has only the old `unilever-logo.svg` and `tdi-logo.svg` (no
   `depotflow-*`, no `tdi-mark.png`). I did not edit shared files. `reportBrand.tsx` + `brandConst.ts` are local stand-ins: the client logo
   (`/brand/unilever-logo.svg`, unmodified, on a white tile, min height 32 px), the text "DepotFlow", and "Developed by TDI Pvt. Limited"
   (`footer.developedBy` in reports.json with `{{company}}`). **22.9: delete `reportBrand.tsx` and `brandConst.ts`, use `ClientLogo`,
   `ProductName`, `DevelopedBy variant="print"`** (3 call sites: `ReportDocument.tsx` header and footer).
2. **"Alerts raised" is not shown.** The report has no "raised" count (only `kpi.openAlerts`, the state at the end). The tile is "Open alerts at the end"
   (critical + warn, like the KPI chip, with the critical / warn split). Not measurable, so hidden rather than a dash (metric admission rule).
3. **Handover groups come from `topEvents`.** The report carries at most the backend's top events, not every open alert. Group counts are
   `selectAlertGroups` over the open or acknowledged `topEvents` the role may see (same function as the KPI popover). When `kpi.openAlerts` total is
   larger than what is listed, the page says "N of M open alerts are listed". **Backend/contract question for the owner:** should the report carry a
   full per-group open count?
4. **Trucks completed** = visits with `departedAt` (the same set as the truck log), not `kpi.turnaround.n`.
5. **Occupancy headline** appears only when `kpi.turnaround` exists (rev 1.1). On an older backend it is hidden; depot turnaround falls back to `kpi.avgTatMin`.
   The bays table totals row uses the depot occupancy headline (a mean of per-bay means would be wrong).
6. **Unknown values are "—"** (em dash, the project rule in CLAUDE.md and the output of `formatDurationMin`), not a hyphen "-" as the brief writes it. One constant: `DASH` in `reportFmt.ts`.
7. **Truck log order** = arrival time ascending, ties by visit id. "Time order" in the spec is ambiguous between arrival and departure; arrival is the first time column.
8. **CSV**: headers in the UI language, numbers as plain latin digits with a dot (machine-readable), plates in two columns (Bangla, English), times as ISO with +06:00,
   no totals row in the Bays file (so a pivot never double counts), cells starting with `= + - @` get a leading apostrophe (formula injection), CRLF line ends.
   File names: `report-<kind>-<date>[-<shift>]-bays.csv` and `...-truck-log.csv`.
9. **Print colours are paper values, not tokens.** `reports-print.css` forces dark ink on white inside the sheet (so a print from the dark theme is readable), draws pills as bordered text,
   and keeps a red outline on the evidence box. This is the one place the "tokens only" rule is set aside; it needs the owner's eye.
10. **`useReport` has no `enabled` option**, so the previous-period request is a `useQuery` over the same `reportKeys` / `getReport` (shares the cache). No `src/data` edit.
11. **`EvidenceImage` cannot report load or error**, so `EvidenceThumb` is built here on `useMediaUrl` and `bboxPercent`. It also avoids the `events` i18n namespace in the reports chunk.
12. No XLSX button, no per-worker data, no ranking, no `/analytics/people`. Captains show name and bays only, in bay order; the section is absent for roles that cannot see names.
13. The print button is disabled until every evidence thumbnail has loaded or failed, or 15 s have passed (`THUMB_WAIT_MS`), so a hung presign cannot block printing for ever.

## Print mechanics (untested; see checklist)
- `@page` A4 portrait and 12 mm margins come from `index.css` (22.0). This task adds none.
- The document sits in a one-cell display-table frame in print: its `table-footer-group` repeats on every page and reserves 10 mm for the footer, which is `position: fixed; bottom: 0`.
- Sections `break-inside: avoid`; the truck log may split between rows (`rp-section--flow`); `tr`, `figure`, `li` avoid breaks; `thead` repeats; `h2` `break-after: avoid`.
- Block flow, not flex or grid, for the stack and sections, so they fragment across pages.
- Body 9 pt, tables compact, headlines 3 columns, evidence 5 columns.
