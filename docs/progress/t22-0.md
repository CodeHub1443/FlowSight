### Rules for the sessions that import this
- **Chunking.** Shell and live code (bell, toasts, tray links) must import `eventsPath` / `eventPath` from `@/features/events/urlState`, and
  `EvidenceImage` from `@/features/events/EvidenceImage`, never from the `@/features/events` barrel, or the events chunk enters the /live entry.
  The data hooks live in `eventQueries.ts` and `reportQueries.ts` (not `queries.ts`) for the same reason; import them from those files, not from
  `@/data/api` (the barrel is fine for the bundle, but a direct import keeps the intent clear).
- **Lifecycle messages invalidate nothing.** Lists merge live open events by id; `useEventAction` already updates the alertStore, the detail cache
  and every cached list page, and rolls all three back on error. A 403 rejects with `NotPermittedError` (show "not permitted", not a generic error).
- **`group` and `groupBy`** are not sent to the server. Filter the fetched rows with `matchesAlertGroup` (same predicate as the KPI popover).
- **Print.** Top bar, map controls, footer and toaster are `print:hidden`; the shell no longer clips a page at the viewport height when printing.

## Decisions
1. **Hooks in their own modules** (`eventQueries.ts`, `reportQueries.ts`) instead of `queries.ts`: the entry chunk already carries `queries.ts`
   (BACKLOG, Task 20.9); adding the new hooks there would have broken the +3 kB budget.
2. **`apiPost` added to `client.ts`**; `apiGet` and `apiPost` share one `send()`. `client.ts` is not named in spec section 2, but it is `src/data/**`,
   owned by 22.0, and the mutations cannot be written without it.
3. **`parseEventFilters(params, role?)`**: the second argument is optional and drops categories the role cannot view; without it nothing is dropped.
4. **`from` / `to` in the URL** are ISO with the Dhaka offset (`2026-11-06T06:00:00+06:00`); a plain `yyyy-MM-dd` is also read, as the start of that day.
   A range whose start is not before its end is ignored.
5. **Presign cache** is a React Query `staleTime` computed from `expiresAt` minus 30 s (no second cache layer).
6. **Print `print:hidden` on the live Tray and VisitTracker was not done**: both are under `src/features/live/**`, which this brief prohibits editing. They are
   only mounted on /live, so a printed report never contains them. Logged in BACKLOG.
