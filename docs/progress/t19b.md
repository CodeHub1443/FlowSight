## Decisions
1. **Clock.** `BayTimeline` and the More details body call `useNow1Hz()`; nothing else ticks. BayBody no longer calls `useStreamNow()`, so the
   card shell re-renders only on BayState changes. The More details body is its own component: collapsed, it is unmounted and does not subscribe.
2. **"So far" rounding.** A running segment and a running occupancy are elapsed counters: `durHM(Math.floor(min))` + "so far". Closed segments use
   `durHM(min)` (rounded, as the 19.0 comment on `TimelineSegment.min` suggests). Mixed rounding can make the occupancy differ by 1 min from the
   sum of the displayed phases.
3. **Phases not started yet** show "—" with the tooltip "Not started yet" (temporarily unknown, spec section 0). The bar always renders three
   segments in a fixed order, so widths glide (`transition-[width]`) and nothing mounts per tick. The running segment is at 60 % opacity.
4. **Segment colours:** pre-op `warn`, work `ok`, post-op `neutral` (tokens only). 19A draws its own stacked bar in the turnaround popover; **19.9
   should align the two** (see risks).
5. **Truck not docked yet** (phase ARRIVED, `dockedAt` null): a note "Truck arrived, not docked yet" instead of the bar; the ETA row still shows when
   `etaMin` is present. **No truck:** "No truck at this bay"; Throughput and Workforce stay mounted ("Cartons this visit" is "—" with a tooltip).
6. **Work label and cartons this visit follow the belt direction** via the 19.0 `workKindOf` (OUT loading/casesOut, IN unloading/casesIn, NONE falls
   back to the phase, then the counts). The old top progress row (count by phase) moved into Throughput as "Cartons this visit"; the caption
   shows "n / expected" only when `expected` is known (it was "n / —").
7. **Finish ETA** only when `visit.etaMin` is non-null: "13 min left · 20:03" (clock = stream now + etaMin). Hidden otherwise.
8. **De-duplication of the kept rows.** The spec keeps "door, belt line" at the top and also lists belt and door rows for More details. To avoid
   showing a value twice: the top belt line is the direction only; cartons/min is in Throughput; "in this state since" is in More details; the door
   row stays at the top only. Today's cartons, trucks and avg turnaround are in Throughput only; damage and fall-offs in More details.
9. **Storekeeper = captain.** The spec maps "storekeeper detected" to `crew.captain.present`, while the kept captain line uses the `live` word
   "Captain". The Workforce label reads "Storekeeper (captain) detected" / "স্টোরকিপার (ক্যাপ্টেন) শনাক্ত" so the two rows are not read as two
   people. The captain's name appears only on the captain line (payload + role gate via `captainName`), never in Workforce. Captain null counts
   as "No". "No" is `warn` while a truck is at the bay, `neutral` otherwise.
10. **SKUs detected** shows `visit.skuCount`; absent or null → "—" with "Not reported by the backend yet"; no truck → "—" with "No truck at this bay".
11. **More details** reuses `CollapsiblePanel` (a FloatingCard) inside the inspector card with `shadow-none!`, header "More details", chevron
    labels "Show more details" / "Hide more details". Its open state persists while the inspector stays on bay bodies (no key per bay).
12. **Avg turnaround today** now uses `durHM` ("58m", "1h 05m") instead of `dur` (which printed seconds).
13. Privacy: no idle or phone time, no per-person rankings, no person-level behaviour anywhere in the panel; unit and e2e tests assert
    `/phone|idle/i` is absent with More details expanded.

## Risks for 19.9
- **Stacked bar colours** may differ from the 19A turnaround popover bar; pick one mapping (this panel: pre-op warn, work ok, post-op neutral).
- **Inspector height at 1366×768:** three new sections plus the kept rows make the body longer than before; it scrolls inside the card
  (`scroll-fade`). Check that Truck timeline is visible without scrolling and the inspector still clears the tray.
- **Nested card:** More details is a FloatingCard inside the inspector card; check the border/blur look in light and dark themes.
- **E2E "no truck" test** relies on a bay standing empty during the 10× peak (retries with `toPass` for up to 120 s, then drops back to 1×). If the
  peak keeps every bay busy, switch it to the default day start.
- Long labels ("Storekeeper (captain) detected", BN "কাজ শুরুর আগের দেরি") sit next to short values; check for wrapping or clipped Bangla glyphs.
